# Hardware references

The original [Raspberry Pi 5 sensor wiring guide](Raspberry_Pi_5_Sensor_Wiring_Guide.docx)
is preserved without editing. Its text and wiring tables are also included in
Appendix C of the [master project plan](../planning/IMMORTALS_MASTER_PROJECT_DOCUMENT_v2.md).

The guide describes the connected prototype. Use master Sections 4, 9, 12,
13, and 15 for the intended sensor inventory, measurement interpretation,
validation, and unresolved hardware choices. DHT22/BMP180 removal candidates,
temperature choice, weight/height/BP additions, power, and enclosure requirements
are tracked in the [implementation status index](../planning/IMPLEMENTATION_STATUS.md).
